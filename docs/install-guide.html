CoolerBox Tracker — Desktop App

Install guide for Windows, Mac and Linux, including what to do when your computer shows a security warning.

Why you will see a warning The desktop app has not yet been signed with the paid certificates that Microsoft and Apple sell, so your computer cannot recognise who made it. It is safe to install as long as the file came straight from CoolerBox Brothers. If you got the file from anywhere else, do not install it.

Windows 10 / 11

Use the file ending in -setup.exe. (If you were also sent an .msi file, ignore it unless you were told to use it.)

  1. Double-click the .exe file you were sent.
  2. A blue window says “Windows protected your PC”. This is the warning described above.
    Click More info, then click Run anyway.
  3. If Windows asks “Do you want to allow this app to make changes?”, click Yes.
  4. Let the installer finish. It starts the app when done. You can open it later from the Start menu: CoolerBox Tracker.
If the file will not download, or disappears Your browser or antivirus may block unsigned programs. In Edge or Chrome open the downloads list, choose Keep (or Keep anyway) on the file. If Windows Security removed it, open Windows Security → Virus & threat protection → Protection history, find the file and choose Restore.

The app needs Microsoft’s WebView2, which is already on Windows 10 and 11. If it is missing, the installer fetches it for you (needs internet).

Mac

Use the file ending in .dmg. It works on both newer (Apple chip) and older (Intel) Macs.

  1. Double-click the .dmg. A window opens showing CoolerBox Tracker.
  2. Drag CoolerBox Tracker onto the Applications folder shown next to it. Then close the window and eject the disk.
  3. Open Applications and open CoolerBox Tracker. The first time, your Mac will refuse. Use the method for your version of macOS:

Mac with macOS 15 (Sequoia) or newer

  1. Try to open the app once. When the warning appears (“Apple could not verify…”), click Done.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the Security section. You will see “CoolerBox Tracker was blocked…”. Click Open Anyway.
  4. Enter your Mac password (or use Touch ID), then click Open Anyway again.

Older macOS (14 Sonoma or earlier)

  1. In Applications, right-click (or hold Control and click) CoolerBox Tracker.
  2. Choose Open, then click Open in the warning box.

You only do this once. After that the app opens normally.

If it says the app is “damaged and can’t be opened” The app is not damaged — macOS adds a download flag that triggers this message. Open Terminal (press Command + Space, type Terminal, press Enter), paste the line below, press Enter, then open the app again: 
xattr -cr "/Applications/CoolerBox Tracker.app"

Linux

You were sent either an .AppImage (works on most distributions) or a .deb (Ubuntu, Debian, Linux Mint, Pop!_OS). Choose one — you do not need both.

Option A — AppImage (no installation)

  1. Save the file somewhere you will remember, for example your Applications or Downloads folder.
  2. Make it runnable. In a terminal, in that folder: 
    chmod +x CoolerBox*.AppImage
    (Or right-click the file → Properties → Permissions → Allow executing file as program.)
  3. Double-click it, or run ./CoolerBox*.AppImage.
If the AppImage will not start (Ubuntu 22.04 and newer) AppImages need a small helper called FUSE. Install it, then try again: 
# Ubuntu 22.04
sudo apt install libfuse2
# Ubuntu 24.04 and newer
sudo apt install libfuse2t64

Option B — .deb package

sudo apt install ./CoolerBox*.deb

(Run this in the folder holding the file. apt will also fetch any parts the app needs.) Then open CoolerBox Tracker from your applications menu.

Tray icon on GNOME (Ubuntu, Fedora) The app lives in the system tray when you close its window. GNOME hides tray icons by default. If you do not see it, install the AppIndicator and KStatusNotifierItem Support extension (search for it in the Extensions app or at extensions.gnome.org). KDE, XFCE, Cinnamon and MATE show it without extra steps.

First launch & how the app behaves

  • Signing in: use your email and password. “Continue with Google” does not work inside the desktop app yet — please use email and password.
  • Stay signed in: you should not need to sign in again every time you open the app.
  • Notifications: when asked to allow notifications, choose Allow. New messages and approvals appear as a banner within about a minute, and the number of unread items shows on the app icon.
    If banners do not appear: Windows — Settings → System → Notifications (and turn off Focus assist / Do not disturb); Mac — System Settings → Notifications → CoolerBox Tracker → Allow.
  • Closing the window does not quit the app. It keeps running in the background (system tray on Windows/Linux, menu bar on Mac) so notifications still arrive. To quit completely, click the tray/menu-bar icon and choose Quit.
  • Downloads (PDFs, files) save to your normal Downloads folder, and a banner confirms when they finish. Some attachment links open in your web browser instead.
  • Saved for offline: open it from the tray/menu-bar icon to keep copies of call sheets, quotes and invoices you can read without internet.

Troubleshooting

What you seeWhat to try
“We could not confirm you are a person” when signing inMake sure you are using the latest version of the app you were sent. Check your internet connection and try again. If it keeps happening, send us a screenshot.
A web browser opens by itself on launch or sign-inYou are running an older test version. Install the newest file you were sent.
Blank or white windowCheck your internet connection (the app needs it). Quit from the tray icon, then open the app again.
I closed the window and can’t find the appIt is still running. Click its icon in the system tray (bottom-right on Windows, top-right menu bar on Mac) and choose Show Tracker.
No notification bannersSee “Notifications” above — the computer’s own notification settings must allow them. The app checks about once a minute.
A download did nothingLook in your Downloads folder. Some links open in your browser instead — save the file from there.
Mac says “damaged” or “cannot verify”See the Mac section above (Open Anyway, or the xattr command).

Updating and uninstalling

  • Website changes appear automatically. You do not need to reinstall for them.
  • New app versions: for now, install the newer file you are sent over the old one. Your sign-in and settings are kept.
  • Uninstall — Windows: Settings → Apps → Installed apps → CoolerBox Tracker → Uninstall.
  • Uninstall — Mac: quit the app, then drag CoolerBox Tracker from Applications to the Bin.
  • Uninstall — Linux: delete the AppImage file, or for the .deb run sudo apt remove cooler-box-tracker.
