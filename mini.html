    Settings
    Project timer

    This is here only to help you: so your project time stays up to date and nothing you worked on gets missed.

    Your screen and your files stay private. Nobody at CoolerBox or your company can see what you're working on.

    What it looks at, on this computer only

    • Which app is in front, and the name of its window (like "Logo_v3.psd"), only for the apps you pick. Every other app is ignored.
    • When a file was last saved in a folder you link to a project. It never opens a file or reads what's in it.
    • Only while this is on and no project timer is running.

    What it never does

    • It never records your screen, takes screenshots or captures images. (macOS calls the permission it needs "Screen Recording"; the app uses it only to read window names.)
    • It never sends or saves window names, file names or folder contents. They're matched to a project the moment they're seen, then forgotten. ("Right now" in Settings shows the window it's looking at, on this computer only.)
    • It never logs time by itself.

    What the tracker gets

    • Nothing, until you tap "Log it". Then only the project and the start and end time, the same as adding time by hand.
    • Your company can't switch this on for you. The app doesn't report whether it's on, or how you use it.

    What stays on this computer

    • The apps you picked and the folders you linked.
    • Suggestions you haven't answered: just a project and two times, deleted after 7 days.

    Switching it off stops all of it straight away.

    ✓ Window names: macOS lets the app read them.
